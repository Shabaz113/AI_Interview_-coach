# AI Interview Coach

An AI-powered Interview Coaching Assistant that helps candidates prepare for technical, behavioral, and situational interviews.

## Features

* Mock interview simulation
* Role-based question bank
* Real-time feedback
* Behavioral and technical questions
* Confidence-building interview practice

## Technologies

* Python
* Object-Oriented Programming

## Run Project

```bash
git clone https://github.com/yourusername/AI-Interview-Coach.git

cd AI-Interview-Coach

python app.py
```
